# Paso para desplegar el Proyecto 
- git 
- git clone https://github.com/Anibal89/2023-02-27-Luis_Zapeta.git

# Servidor
- Ingresar a carpeta con cd servidor en terminal 
- Descargar dependencias con npm install
- Cambiar archivo de configuracion .env en los siguientes parametros 
- DB_PORT=3306   
- DB_HOST=localhost
- DB_USER=anibal
- DB_PASSWORD=ReactJs100
- DB_DATABASE=sucursal
- Ejecutar servidor npm run dev

# Base de datos
- Ejecutar script llamado "db.sql" en mysql ubicado en el directorio cd Base de Datos/Query de la base de datos/

# Aplicacion
- Ingresar a carpeta con cd prueba en terminal 
- Descargar dependencias con yarn install
- Ejecutar aplicacion npm run dev
